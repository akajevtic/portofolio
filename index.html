Weak Keys

A typing trainer that finds what you type badly and drills exactly that.

A browser typing test that tracks the keys, words and letter pairs you miss, then builds practice from them. An optional AI coach, Claude or Gemini, reads your whole history and says what is improving, what is stuck and what to drill next. No account, no server, nothing to install.

03 / 052026

Traffic Law RAG

Question answering over Serbia's road safety law.

Three retrieval pipelines compared on the same 362 articles: fixed-size chunks with exact search, article-aware chunks on an HNSW index, and a third that adds cross-encoder reranking and pulls whole articles back hierarchically. Embeddings and reranking run locally; the answer comes from an LLM on Groq.

  • Python
  • FAISS
  • sentence-transformers
  • Reranking
  • Groq

04 / 052026

RAF LMS

An exam platform for programming courses.

A teacher sets a task, students solve it in a desktop editor and hand it in, and the teacher follows the session live and grades with comments on individual lines of code. Three parts: a Spring Boot REST API with JWT and MySQL, an Electron editor built on Monaco, and a React dashboard for monitoring.

  • Java
  • Spring Boot
  • MySQL
  • JWT
  • Electron
  • React

05 / 052026

Parallel Pareto

One multi-objective search, written three ways.

The same Pareto optimization implemented sequentially, with threads over shared state behind locks, and as separate processes that trade candidates over a ring and other topologies. Each version is measured against the others, with hypervolume as the yardstick for the quality of the front.
